# 百戦錬磨 忍者さゆり BATTLE DX

さゆりバトルのWebゲームページです。PC・スマートフォンのブラウザからそのまま遊べます。

## 🎮 遊び方・目的
敵を規定数たおすと**門**が開きます。開いた門に飛びこむか、**姫**にふれるとステージクリアです。

### 操作方法
* **PC：** WASD / 矢印キーで移動、J / スペース長押しで手裏剣連射、K / Shiftで必殺手裏剣、Escで一時停止
* **スマホ：** 左下スティックで移動、右下ボタン長押しで連射、上の必殺ボタンで全方位攻撃

### アイテム
* 📜 **巻物：** 必殺手裏剣（16方向攻撃）を解放
* 🍡 **だんご：** 体力回復
* 🕯️ **ろうそく：** 火炎放射（8秒）
